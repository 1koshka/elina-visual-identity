Elina is an AI-based Telegram companion. This project explores a read-only connection to the owner's authorized Pinterest account so Elina can browse visual inspiration. Telegram avatars will use original images or images with independently verified reuse rights, not Pinterest API content.

Pinterest API connection: in development

Read our privacy policy →

Explore inspiration

With permission, retrieve eligible boards and Pins from the connected account. No access to unrelated users' private collections.

Choose deliberately

Assess the visual style of the owner-selected inspiration. Pinterest API materials will not be sent to third-party AI services or used to train models.

Update with control

A separate planned Telegram feature can update profile photos from original or appropriately licensed image sources, preserve a previous photo for rollback and avoid repetitive changes.

How the integration is intended to work

The Pinterest integration is not yet connected or approved. If approved, the account owner will authorize access using Pinterest OAuth. We intend to request only boards:read and pins:read for ordinary public boards and Pins. The app will not create Pins, post comments, run ads, or manage other users' accounts.

Pinterest is an inspiration source, not a source of automatically reusable images. The app will not scrape Pinterest, retain Pinterest API content in a local media library, transmit it to Google Gemini or distribute derivative works based on Pins. Any Telegram avatar must come from an independent, original or properly licensed source.

Privacy by design

The project is operated for a single authorized Pinterest account. OAuth credentials are never placed on this public website. No advertising or tracking scripts are embedded here. External services involved in the optional future workflow are explained in the privacy policy.

Project disclosure: Elina is artificial intelligence, not a human being. This page is an informational website for a personal project; it does not sell services or offer public registration.
