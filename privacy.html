Privacy and data handling

Privacy Policy

Effective: October 23, 2026 · Project: Elina Visual Identity · Operator: Owner of the personal Elina AI project

Current status: The Pinterest API integration described below is under development. We do not claim that Pinterest has approved an app or that OAuth access is active. This policy describes the intended processing if and when the owner enables the integration.

1. About this project

Elina Visual Identity is a personal, non-commercial AI companion integration intended for a single Pinterest account authorized by its owner. Its purpose is to read selected Pinterest boards and Pins to display visual inspiration to the authorized account owner. A separate Telegram avatar feature may use original or properly licensed images sourced independently from Pinterest. There is no public user registration or advertising service.

2. Data we may process

  • The Pinterest account identifier and eligible board/Pin metadata accessed temporarily during an authorized API request. Pinterest API materials will be fetched as needed instead of retained in a persistent catalogue.
  • OAuth access and refresh credentials needed to access the authorized account, stored in the operator-controlled runtime rather than on this website.
  • Change dates and references to Telegram avatars generated or obtained independently with appropriate reuse rights (not Pinterest API images).
  • Independently generated or licensed avatar image files used for optional Telegram profile updates. Pinterest content is not downloaded for republishing.

We do not request access to private/secret boards or Pins, passwords, direct messages, advertising accounts or payment information. We do not intentionally collect sensitive personal data from other Pinterest users.

3. Why we use the data

Only to display permitted inspiration from the authorized account, help manage independently sourced and permitted Telegram avatars, troubleshoot failures, and respond to data requests. The owner controls whether the integration is enabled.

4. Services involved and disclosures

  • Pinterest: authentication and read-only access to the authorized account, governed by Pinterest's terms and privacy policy.
  • Telegram: a chosen avatar may be uploaded to Elina's Telegram account. A published profile image can become visible to other Telegram users subject to Telegram's settings.
  • Google Gemini, if enabled: may evaluate original or independently licensed candidate avatar images. No Pinterest API materials will be sent to Gemini or used to train or improve AI models.
  • GitHub Pages: hosts this informational website and may process routine server/access information under GitHub's own practices.

No Pinterest data is sold, used for targeted advertising, provided to unrelated third parties, or republished as a Telegram avatar by this project. Pinterest API materials will not be used as model-training data.

5. Storage, security and retention

Once enabled, minimal operational records are intended to be stored on the operator-controlled device in access-restricted files and a local database. Credentials must not appear in public repositories, front-end code or logs. Pinterest API information is retrieved on demand rather than stored as a persistent library. Limited dates and references for independently obtained Telegram avatars may be retained while the feature is active to support rollback, and removed when no longer necessary or when the account owner requests deletion. Temporary independently sourced files should be deleted after processing where feasible. An installed Telegram avatar and service-side copies may persist under Telegram's retention rules until changed or removed.

No online service or local device can guarantee absolute security. The operator should revoke tokens promptly if compromised.

6. Your choices and requests

The Pinterest account owner may deny authorization, disconnect the integration, revoke app access in Pinterest's connected-app settings when available, and request deletion of any Pinterest-derived data that might remain following exceptional errors or troubleshooting. Revocation prevents new authorized API access but does not automatically delete previously published Telegram photos or information held independently by Pinterest, Google, Telegram or GitHub.

For privacy or access requests, contact the project operator by writing to Elina on Telegram (@elina_ai) and clearly indicate that the message is a privacy request for the operator. Elina is an AI account; messages from new contacts may require operator approval. Do not include passwords, authentication codes or sensitive documents in your first message.

7. Website privacy

This site does not include project-controlled analytics, advertising scripts, forms or tracking cookies. GitHub Pages may process technical request logs as the website hosting provider. External links are subject to the destination service's policies.

8. Children, changes and limitations

This integration is not directed at children and does not provide general consumer services. This notice may change when actual processing capabilities, providers or data retention practices change. The date at the top will be revised for material updates. This description does not override Pinterest content rights, platform rules or applicable privacy law.

Политика конфиденциальности — версия на русском

Назначение

Elina Visual Identity — личный некоммерческий проект ИИ-собеседницы Элины. Интеграция Pinterest пока разрабатывается. После авторизации владельца планируется чтение выбранных досок и пинов для поиска визуальных референсов и выбора аватара Telegram.

Какие данные обрабатываются

Только необходимые для запросов сведения аккаунта, досок и пинов, а также токены OAuth. Данные Pinterest не будут сохраняться в постоянной библиотеке. История аватаров относится только к оригинальным или отдельно лицензированным изображениям. Доступ к секретным доскам, паролям и сообщениям не запрашивается.

Передача и хранение

Токены OAuth планируется хранить локально в среде владельца с ограничением доступа. Данные Pinterest будут запрашиваться по мере необходимости и не передаваться в Gemini; для анализа с Gemini допускаются только независимо полученные оригинальные или лицензированные изображения. При установке аватара такое изображение передаётся Telegram. Этот сайт размещается через GitHub Pages и не содержит собственных рекламных или аналитических скриптов. Данные не продаются и не используются для рекламы.

Права и связь

Владелец может отключить интеграцию, отозвать доступ Pinterest и запросить удаление локальных данных. Смена или отзыв доступа не удаляет автоматически уже установленный в Telegram аватар. По вопросам конфиденциальности можно обратиться к оператору проекта через @elina_ai в Telegram, указав, что сообщение адресовано владельцу. Не присылайте пароли и коды.
